# Publish to Portal

ทำให้ PA เผยแพร่งานขึ้นพอร์ทัลได้แค่ "บอก Claude" — ไม่ต้องแตะโค้ด ไม่ต้องพิมพ์ meta tag เอง

## หลักการ
PA สร้างผลลัพธ์ออกมาเป็นไฟล์ (มักเป็น HTML) → สกิลนี้เติม `<meta name="portal:*">` ให้อัตโนมัติ
วางในโฟลเดอร์หมวดที่ถูก แล้ว push ผ่านสคริปต์ `scripts/publish.js` ที่เตรียมไว้ในตัว repo

> ทำงานในโฟลเดอร์ repo พอร์ทัลของคุณเท่านั้น · ห้ามแก้ `scripts/` หรือ `build-index.js` — แค่เรียกใช้

## ขั้นตอน

### 1) หาไฟล์ต้นทาง
- ถ้าผู้ใช้ระบุ path มาแล้ว ใช้เลย (รับ path ที่ไหนก็ได้ เช่น `~/Downloads/brief.html`)
- ถ้าเพิ่งสร้างไฟล์ในบทสนทนานี้ ใช้ไฟล์นั้น
- ถ้าไม่ชัด ให้ถามสั้น ๆ ว่าจะเอาไฟล์ไหนขึ้น

### 2) กำหนดข้อมูล (เดาให้มากที่สุด ถามให้น้อยที่สุด)
- **category** — เลือก 1 ใน 3:
  - `morning-brief` → สรุปประจำเช้าของ CEO (ปักหมุดบนสุดให้อัตโนมัติ)
  - `projects` → งานที่ผูกกับโปรเจค → ต้องมี **ชื่อโปรเจค**
  - `reports` → รายงานทั่วไป
  - ถ้าเดาไม่ได้ ให้ถาม
- **project** (เฉพาะ projects) — ก่อนถาม ให้ดูโฟลเดอร์ที่มีอยู่ใน `content/projects/` เพื่อใช้ชื่อเดิมให้ตรง
- **title** — ดึงจาก `<title>`/`<h1>` ของไฟล์ หรือสรุปจากเนื้อหา
- **summary** — เขียนคำโปรยภาษาไทย 1 บรรทัด (สั้น กระชับ ~ไม่เกิน 80 ตัวอักษร) จากเนื้อหา
- **slug** — ตั้งชื่อไฟล์เป็น **ภาษาอังกฤษ** สั้น ๆ (a–z, ตัวเลข, ขีด) เสมอ เช่น `sprint-7-update`
- **date** — วันนี้ (เว้นแต่ผู้ใช้ระบุ)

### 3) เรียกสคริปต์
```bash
node scripts/publish.js \
  --file "<path ไฟล์ต้นทาง>" \
  --category <morning-brief|projects|reports> \
  [--project "<ชื่อโปรเจค>"] \
  --title "<ชื่อเรื่อง>" \
  --summary "<คำโปรย 1 บรรทัด>" \
  --slug <eng-slug> \
  --push
```
- สคริปต์จะ: ใส่ meta → วางไฟล์ในโฟลเดอร์หมวด (ชื่อขึ้นต้นด้วยวันที่) → build → commit → push
- ถ้าอยากให้ผู้ใช้ดูก่อน push: รัน**โดยไม่ใส่** `--push` ก่อน แล้วบอกให้เปิด `public/index.html` ดู จากนั้นค่อยรันซ้ำพร้อม `--push`

### 4) รายงานผล
- บอก path ไฟล์ที่สร้าง + ว่า push แล้ว Vercel กำลัง deploy
- จบด้วยสรุปสั้น ๆ ว่า "ขึ้นพอร์ทัลแล้ว เปิดดูได้ที่เว็บพอร์ทัลของคุณ (รออ่านได้ใน ~30 วินาที)"

## กรณีไฟล์ไม่ใช่ HTML
- **.md / ข้อความล้วน** → แปลงเป็น HTML ง่าย ๆ ก่อน แล้วค่อยส่งให้ `publish.js`
- **.pdf / รูปภาพ** → ก๊อปไฟล์เข้าโฟลเดอร์หมวด แล้วสร้างหน้า HTML สั้น ๆ ที่ลิงก์/ฝังไฟล์นั้นเป็นหน้าปก (มี meta ครบ)
- ถ้าเป็นชิ้นส่วน HTML (ไม่มี `<head>`) ส่งให้สคริปต์ได้เลย — มันจะห่อด้วยเทมเพลตมาตรฐานให้เอง

## ตัวอย่างบทสนทนา
- ผู้ใช้: *"เอา Morning Brief วันนี้ขึ้นพอร์ทัล"*
  → `node scripts/publish.js --file brief.html --category morning-brief --title "..." --summary "..." --push`
- ผู้ใช้: *"เพิ่มสรุปงานโปรเจค X อันนี้"*
  → `node scripts/publish.js --file out.html --category projects --project "X" --title "..." --summary "..." --slug update --push`
